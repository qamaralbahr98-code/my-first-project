# Dwin — «The Kurdish narrative» (Vox style, about 11 min, ar / ckb / kmr)

1. Collect the files in `ASSETS.md`: 28 real items and 8 ChatGPT images, plus `dwin_logo.png`. Put them in `assets/` and add their credits to `assets/credits.txt`.
2. Record narration from the prompts and save it as `vo/ckb.wav`, `vo/kmr.wav` and `vo/ar.wav`.
3. Give this folder to Claude Code and say: "Read CLAUDE.md and build all three videos, then the thumbnails."

Contents:
- `prompts/`: the full brief for each language.
- `subtitles/`: estimated SRT files.
- `social/`: the YouTube title, description, chapters and tags, plus Facebook and Instagram captions.
- `THUMBNAILS.md`, `MOTION.md`, `ASSETS.md`.

Structure:
1. Hook (S01–S04)
2. Context (S05–S13)
3. Core problem (S14–S18)
4. Evidence (S19–S26)
5. Counterarguments (S27–S32)
6. Stakes (S33–S36)
7. Closing (S37–S39)
