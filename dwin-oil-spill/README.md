# Dwin Vox explainer: UAE oil spill (October 2026) — Sorani & Kurmanji

- `prompts/01_sorani.md` and `prompts/02_kurmanji.md`: full production prompts (English instructions; narration and on-screen text in Kurdish).
- `IMAGES.md`: the 17 images the video needs, with file names and AI descriptions.
- `script/scenes.json`: source of truth. Edit it, then run `python3 tools/build.py`.

Corrections to the source text: the slick is 25 km (not miles) off Umm Al Quwain; the tanker is "Gem No.2"; the Copernicus images were taken 19–21 October (not 11–15).
